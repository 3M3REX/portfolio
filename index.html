Product

EmerTool

An After Effects panel that removes the routine motion designers lose hours to.

The problem

Editors lose hours on the same things: hunting for sounds, rebuilding easing curves, cleaning bloated projects, setting up renders by hand.

What is inside

  • Easing editor with curve presets
  • Sound library: categories, search, waveform preview
  • Animated text templates with batch input
  • Asset browser: images, video, icons, 3D
  • Subtitles, keyframe graphs, project load analysis
  • Cache cleanup, one-click render, YouTube search
  • Hoshi — assistant that finds the asset you ask for

Role: product idea, UI/UX and specification are mine. Development done with AI assistance. Working build, preparing for release.
